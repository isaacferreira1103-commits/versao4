# Explore o Universo

## 🚀 Sobre o projeto

**Explore o Universo** é um projeto didático desenvolvido para o aprendizado de **JavaScript aplicado a páginas web**.

A proposta é partir de uma página construída com HTML e CSS e evoluí-la gradualmente, adicionando interatividade e novos comportamentos com JavaScript. 

Ao longo das versões do projeto, são trabalhados conceitos como seleção e manipulação de elementos do DOM, eventos, classes, atributos, estruturas condicionais e outros recursos da linguagem.

O objetivo é aprender JavaScript de forma prática e progressiva, utilizando situações que fazem parte do desenvolvimento de um site real.
